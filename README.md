# Учёт личных финансов

Настольное приложение для учёта личных финансов: доходы, расходы, инвестиции,
имущество и дивидендно-купонный календарь.

`tkinter + SQLite` — только стандартная библиотека Python, без сторонних зависимостей.

</div>

---

## Возможности

- **Операции** — доходы, расходы и инвестиции с фильтрами по периоду, виду и
  категории, поиск по категории.
- **Категории и планы** — свои категории, месячные планы по каждой из них.
- **Статистика** — кольцо структуры расходов за месяц, план/факт по категориям,
  тренд доходов и расходов за 12 месяцев (графики рисуются на Canvas).
- **Импорт выписок** — Т-Банк (CSV/XLSX) и OFX, с определением дублей.
- **Инвестиции** — бумаги MOEX и США, имущество и ручные активы, сделки
  покупки/продажи, портфель и доходность.
- **Календарь выплат** — дивиденды и купоны, онлайн-подтягивание дат выплат
  через MOEX ISS; фоновое автообновление котировок.
- **Темы** — светлая и тёмная: переключаются кнопкой в шапке и применяются
  мгновенно, без перезапуска.
- **Горячие клавиши** — `Ctrl+N` новая операция, `Ctrl+I` импорт выписок,
  `F5` / `Ctrl+R` обновление активным/всех табов, `Esc` отмена форм.

Онлайн-функции (котировки, поиск бумаг) работают, только когда есть сеть;
без сети приложение продолжает нормально работать.

## Быстрый старт

Нужен Python 3.10+ (tkinter включён в стандартные сборки).

```bash
git clone https://github.com/MrRobot-sys/personal-finance.git
cd personal-finance
python main.py
```

Файл базы `finance.db` создаётся рядом с запускаемым кодом автоматически;
путь к своей базе можно указать через `--db путь/к/base.db`.

## Проверки

```bash
python main.py --selftest  # логика: модели, сервисы, импортеры, котировки (offline)
python main.py --smoke     # краткая проверка интерфейса: окно строится и закрывается
```

## Сборка exe (Windows)

```bat
pyinstaller --noconfirm --clean finance.spec
:: результат: dist\PersonalFinance.exe (onefile, без консоли, база создаётся рядом)
```

Референсная сборка идёт скриптом `build.bat` и в GitHub Actions.

Иконку приложения (и окна, и exe) можно перегенерировать:

```bash
python3 scripts/make_icon.py   # чистый Python, рисует PNG и ICO в finance/ui/assets
```

## Структура проекта

```
main.py                Точка входа (CLI: --db, --selftest, --smoke)
finance/
  db.py                SQLite: схема, миграции, сиды
  models.py            Дата-классы, валидация, форматирование
  repository.py        SQL-CRUD, фильтры, агрегаты
  services/            Бизнес-логика: FinanceService (фасад) + доменные сервисы
  importers.py         Парсеры выписок Т-Банк (CSV/XLSX) и OFX
  quotes.py            Онлайн-котировки: MOEX ISS, Yahoo Finance, ЦБ РФ, smart-lab
  selftest.py          Самопроверка логики (--selftest)
  ui/                  Интерфейс: app.py, tabs/, dialogs/, widgets/ (тема, графики)
finance.spec           PyInstaller-спецификация Windows-exe
scripts/make_icon.py   Генератор иконки приложения
example/               Примеры выписок (не в репозитории)
```

## Статус

Личный проект в активной разработке. Данные пользователей (`finance.db`,
`example/`) в репозиторий не попадают — они в `.gitignore`.
